Engineering & platform work

Speed & caching

Caching throughout - TanStack Query, dashboard and reference-data caches, and instant-from-cache screen loads - so pages load fast and the servers do less work.

Reliability at the root

Fixed underlying causes of random errors and slowdowns: database connection over-commitment (random 500s), the periodic freeze, list lag at scale, and the blank-screen problem.

Security hardening

Database row-level security across every table, encrypted sensitive data, step-up MFA, and web-security hardening (CSP / XSS).

Infrastructure & deployment

Microsoft login, live servers and database, and automatic deployments with cache-safety and rollback protection.

Testing & quality gates

Automated tests that block a broken release before it reaches staff, plus end-to-end payroll math tests run on every change.

Mobile

Every screen works on phones - card layouts, touch targets, and mobile navigation.

The latest chapter · this weekend's payroll build

A full fixed-salary payroll model - built, tested, hardened

Before

The timecard handled hourly pay only. Salaried staff had no attendance-based pay run, and employees couldn't see or correct their own timecard.

After

A monthly-salary pay model with attendance bands (present / half day / absent / working), weekend overtime, and INR/USD currency. Employees see the same payroll timecard HR sees and can fix punches as approver-confirmed requests - with a three-signature sign-off and a finalize that locks the month.

Verified

Every payroll change was checked by an end-to-end test suite (hourly and fixed engines), then a three-agent code audit caught and fixed a timezone-boundary deduction bug, an approval-vs-signature conflict, and a mid-month finalize that could re-price - before any of it reached a paycheck.

Full weekend log (Fri–Mon): the fixed-salary payroll model above, plus the employee Time Clock, a ~16-second periodic-freeze fix, a never-white-screen safety net, automated tests in CI, standardized loading across the app, and the on-brand dialog system.
