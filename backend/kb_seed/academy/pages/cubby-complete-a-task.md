## What You'll Be Able to Do

- Find the tasks due today on the shared task list.
- Know which tasks Cubby's workflows create and what each asks you to do.
- Complete a task with a note that records what you did.
- Know the difference between completing and archiving.
- Create your own task, and reopen a task when you need to change it.

## Before You Start

- Cubby keeps **one shared task list** for the site, on the computer and the phone app.
- A task is **Open**, **Completed** or **Archived**. Archived means dismissed, **not** done.
- A completed or archived task cannot be edited. To change it, reopen it first.
- Completing a **repeating** task creates the next one.
- Where a button's exact name is not given, the button name in Greens' Cubby is on the screenshot.

## The Tasks Workflows Create

Most tasks at Greens are made by Cubby's workflows. The number in the title is the day in the delinquency count (From Greens' Cubby, 11/2026):

| Task | What you do | How many in a year |
|---|---|---|
| 2nd - Call Failed Autopay Tenants | Call each tenant whose autopay was declined on the 1st | 2,152 |
| 2nd - Call Failed Autopay Mailbox Customer | The same, for mailbox customers | 39 |
| 2nd - Call Failed Autopay Waste Dump User | The same, for dump station users | 3 |
| 6th - Call Past Due Tenants | Call everyone still unpaid | 428 |
| 6th - Call Past Due Mailbox Customer | The same, for mailbox customers | 10 |
| 30th - Final Collection Call | The last call before the lien notice | 12 |
| 35th - CA Lien Notice | The lien notice step (Cubby How-To: Start a Lien) | 11 |
| 61st - Vehicle Lien Filing/Tow Notice | The vehicle lien step | 4 |
| 62nd - Publish 2nd Lien Sale Ad | The second sale ad | 7 |
| Remind Tenant of POI Obligation | Ask for current proof of insurance | 61 |
| Enroll Tenant in Protection Plan | Offer the protection plan to a tenant with no current proof of insurance | 50 |

> [!NOTE]
> A task's stored due date can look one day earlier than its title. Cubby stores the date in UTC and creates the task the evening before. Work the "2nd" task on the 2nd.

## Steps: Work Today's Tasks

1. Open the task list and filter to today and overdue.
2. Work collection tasks first, oldest first. They are time-sensitive.
3. Open each task. Open the lease it links to.
4. **Before calling**, check the lease: has the tenant paid since the task was made? Is there an exemption? If so, complete the task with a note saying so.
5. Do the work: make the call, send the payment link, check the document.
6. Complete the task (the button name in Greens' Cubby is on the screenshot), with a note: what you did and what happens next.

## Completed or Archived?

| Use | When | Example |
|---|---|---|
| **Complete** | You did the work, even if the result was "no answer" | You called and left a voicemail |
| **Archive** | The task should not be done at all | A duplicate task, or one made by mistake |

Never archive a collection task because the tenant did not answer. A call with no answer is a call made: complete it with the note "No answer, voicemail left, payment link sent."

## Steps: Create Your Own Task

1. Create a task (the button name in Greens' Cubby is on the screenshot), from the lease, lead or contact it is about so it links there.
2. Give it a plain title: "Call back about covered space," "Move tenant out of unit 118."
3. Set the due date.
4. Assign it, or leave it for whoever is on shift.
5. Save.

Remember: a task is a reminder, not the action itself. A "Move TNT Out" task does not schedule a move-out; schedule it on the lease too (Cubby How-To: Move-Out).

## Steps: Reopen a Task

1. Find the completed or archived task.
2. Reopen it (the button name in Greens' Cubby is on the screenshot).
3. Make the change, then complete it again.

## Example

**Escondido, the 6th, 9:00 AM.** The list shows 14 "6th - Call Past Due Tenants" tasks and one of your own: "Call back customer about 10x15." You start on the past-due calls. The first tenant paid through the portal at 11:00 PM last night: you complete the task with "Paid 11/05 via portal, no call needed." The second has an exemption with the reason Payment Arrangement: you complete it with "Exemption active, arrangement on track per notes." You call the rest, noting each. At 11:00 AM you return the customer's call about the 10x15 and complete that task too.

## Common Mistakes

1. **Archiving instead of completing.** Archived means not done.
2. **Completing with no note.**
3. **Calling a tenant who already paid** because you did not check the lease first.
4. **Letting tasks go overdue.** A collection task done late is worth much less.
5. **Using a task instead of the real action**, such as a move-out reminder with no scheduled move-out.

## Key Points

- One shared task list; Open, Completed, Archived. Archived is not done.
- Workflow tasks name their day: the 2nd, 6th, 30th, 35th, 61st and 62nd (From Greens' Cubby, 11/2026).
- Check the lease before every collection call.
- Complete every task with a note; reopen to change it.
- Your own tasks are reminders; do the real action on the lease too.
